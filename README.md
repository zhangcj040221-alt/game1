# 一起看星星 · 一二布布

第一张交互卡牌效果样片，使用 Three.js 的分层二维场景。角色是用户确认的 R05 矢量基准，按部件加载，实时做轻微呼吸、眨眼和仰望动作测试。当前不是三维角色，也尚未接入原版 GIF 的完整表演动作。

## 使用

手机或电脑访问仓库的 GitHub Pages 页面。按住卡牌拖动改变角度，松手回正。轻点卡牌或点“许一个愿望”触发流星。四个开关分别控制角色微动、空间视差、粒子、镀闪；暂停控制场景时间。

## 开发

Node.js 24：`npm ci`，`npm run dev`。源码在 `app/`，`npm run build` 输出 `dist/`。依赖和锁文件随仓库保存，预览不依赖外部 CDN。

仓库根目录的 `index.html`、`assets/`、`characters/` 是已构建的 Pages 预览副本，兼容原仓库现有的从 main 根目录发布方式。修改后运行 `npm run build`，再运行 `node tools/sync-pages.mjs` 同步发布副本。

## 验证

`npx playwright install chromium` 后运行 `npx playwright test`。CI 检查桌面与手机尺寸、WebGL 实际初始化、拖动、四个开关、暂停与许愿，并保存截图。云端交互浏览器禁用 WebGL，使用同一 Three.js 场景的 Canvas 兼容渲染检查画面与交互；正式 WebGL 路径由 CI 单独验证。兼容模式简化了镀闪与材质，不代表最终 GPU 效果。

## 素材与后续

- 角色：`app/public/characters/`，R05 已通过基准。原 SVG 不作形变；运行时分组动作是样片姿态测试。
- 星空、月亮、山丘、粒子、卡框：程序绘制的临时美术，尚未确定最终画风。首版复用已有角色素材，未下载第三方图片或粒子包。
- 参考效果：炉石钻石卡、王者万象棋镀闪卡；本项目没有复制它们的游戏素材。
- 下一步：先审核动作、空间层次与闪光感，再筛选原版互动动图/制作正式动作，最后开发正式美术与卡牌组件。

角色资产及原角色形象不因本仓库公开而授予第三方使用许可；第三方依赖保留各自许可。

## B 材质样片 002

当前角色已切换为用户批准的 B 光滑公仔外观，来自批准原图的分层像素提取，不使用早期渐变版 B。`app/public/characters/b-approved` 中的 PNG 为部件紧边界裁切，JSON 保存原始 960×1080画布坐标与绘制信息；一二15层、布布11层。素材来源和隐藏区域限制见原分层资产包。光照已经画进贴图，运行时保持外观，不是三维模型或动态PBR重布光。头部摆动限制为约0.4度，避免尚未补全的隐藏区域露出。眨眼由独立眼睛层实现，底下有修补后的净脸。

自动检查新增素材版本与图层数断言，保留左右拖动四眼像素检查。A画风不受本次更新影响。


## 效果对比 003

`compare.html` 为真正三维角色试版，两版共用 R05 布布的头部与身体轮廓，通过封闭曲面生成体积，并共用角色比例、软陶配色、灯光和布景。A 左右拖动控制摄像机；B 左右拖动控制赠星动作，支持自动播放、三个剧情节点和本地偏好选择。原来的已确认平面 / B 图像基准及 2.5D 页面继续保留。

三维头部厚度、背面、手臂根部和动作是本次新制作的试验性延展，尚未获得造型验收。黏土效果通过 MeshStandardMaterial、真实几何、灯光和实时阴影呈现；本页需要 WebGL，不使用平面图片伪装三维效果。

Playwright 覆盖桌面 / 手机、左右视角、剧情拖动与节点、灯光切换、播放 / 暂停、重置及本地选择持久化。截图保存在 Actions 的 card-browser-verification 中。


## 三维设定参考 R01

`reference.html` 为正交六视图审核页，复用 `character-volume.js` 的同一模型，固定中性站姿和中性灯光。两位角色各含正面、左右观察20度、45度、右侧面和背面。现有正面软陶图以原始分层像素重组作对照。

卡牌摄像机范围按用户确认限制为左右各20度。参考页的侧背面只服务造型审核，不扩大卡牌交互范围。头厚、背面、耳根和肩根以及鞋后跟仍为提案；尺寸基于头宽100归一化，不代表官方尺寸。正式三维基准尚待用户审核。
