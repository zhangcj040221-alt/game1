# 五职业成长与三章冒险：实际修改与数值复验

> 日期：2026-11-23。代码基准：game1/main。此文为当前可复验状态，不是平衡最终验收。
>
> **本轮顺序**：①职业规则偏差／高频失衡；②厨师、老师、工程师及小偷的成长和构筑策略；③第三章消耗敏感性试调。

## 不改变的共同基准

- 三章节共13战；布布首战无职业、战后选职。第2/3/4/6/7/8/10/11/12战后有9次成长机会。小偷以战后采购代替常规成长。
- 玩家30 HP，起手抽4张，通常每回合3次普通行动，可留牌1张。
- 普通战胜利恢复5，精英恢复7，前两章首领战后恢复到30；这次未调整恢复。
- 统一的敌人意图、双怪行动、死亡遗留、失衡打断，不为某个职业重写敌人AI。

## 已落地的修改

**规则与高频控制**

1. 一二对目标的*魔法来源*失衡设恢复窗口：一次魔法失衡后，目标必须实际执行一次攻击才能再次被一二魔法打断。准备、援护和被跳过的行动不解除。其他职业的失衡不受该规则限制。游戏设置提供“魔法韧性”开关，命令行模拟可用 `--no-mage-resilience` 对照。
2. 骑士完美格挡保留先前决定：精准抵挡当前攻击段，并打断该敌人下一次意图；不新增整个玩家回合，攻击状态与失衡加成未改。
3. 厨师酸味从“打出酸牌立即造成两段伤害”改回“先自损、下一次普通攻击追加追击”。试验参数：基础酸自损2、下一次攻击额外等额伤害；高级酸自损3、下次攻击额外200%伤害并抽1。重复酸味不无限叠倍数。料理提炼不会把最后2张基础攻击牌全部删掉。

**成长**

4. 工程师可在战后「更换图纸」与「定向精修」之间选择。每张机关最多精修2级，每级该机关触发伤害+2；跨战保存，更换该牌位清零。不会让一个机关的强化传递给其他敌人。
5. 老师保留两短教案奖励槽、一长期挑战、一主导权限、战内杂事临时改造，未叠加额外系统。测试器不再把先删掉“减势”的衔接路线误判为必需成长；保留旧路线作对照。**指定教材路线仍未合格**。
6. 厨师模拟不再贪心堆出4张高级酸：只从实际出现的3项候选里，按味道覆盖、已有高级料理、保留攻击牌等条件选择，必要时可跳过成长。测试器现在区分纯酸辣甜、咸味辅助与酸辣苦。
7. 小偷道具来源、两格口袋、金币和次数机制不变；增加稳健采购与默认采购策略的对照。终章盗窃无后续商店时不应该被自动策略高估。

## 连续13战配对测试：第三章精英生命 68→62

下面每个格子是**同一批20个随机种子×2种集火顺序，共40局**的通关次数。角色真实携带生命、战后恢复、库存及已取得的成长进入下一战；自动代理控制器有有限前瞻，不能等同真人最优操作。

| 测试构筑 | 精英68 HP时通关 | 精英62 HP时通关 | 变化 |
| --- | ---: | ---: | ---: |
| 小偷·稳健采购 | 20/40 | 26/40 | +6 |
| 工程师·精修 | 12/40 | 16/40 | +4 |
| 老师·纪律 | 7/40 | 8/40 | +1 |
| 老师·衔接保留减势 | 11/40 | 12/40 | +1 |
| 厨师·酸辣甜 | 16/40 | 18/40 | +2 |
| 厨师·咸辅助 | 14/40 | 17/40 | +3 |
| 骑士·剑盾 | 30/40 | 30/40 | 0 |
| 一二·捕获 | 36/40 | 36/40 | 0 |

其余敌人血量和攻击不变。精英仅调了其一场双敌总生命68→62，仍在此前约定的第三章精英58–75生命区间内。**并未以角色特性改变敌人行动逻辑。**

## 关键结构性对照

- 工程师：同一批40局，纯更换机关图纸**2/40**，加入定向精修**12/40**（第三章精英旧数值时）。说明旧九次成长不积累力量确实是缺口。
- 老师：无防护衔接**1/40**，保留减势的衔接**11/40**（精英旧数值时）。并非衔接系统天然不可用，而是选择掉主要生存奖励后无法度过前期。
- 老师指定教材：有衔接也只在旧数值下**0/40**；能更常完成长期教案，但长期权限的优势不足以改善续航，是未解决的真实风险。
- 厨师：精英旧数值下，酸辣甜**16/40**、咸辅助**14/40**、酸辣苦**1/40**。苦味路线风险明显，不能借“正常成长”掩盖。
- 小偷：同样的采购系统，稳定优先选择急救包/防护道具可显著提高整局续航。不能只按最大可使用次数自动采购。
- 一二：魔法韧性开关对照中，捕获路线从约**38/40**降到**36/40**；完全禁止捕获的基础8张魔法路线从**40/40**降到**14/40**。该数字来自同种子20×2的试验，提示曾有严重的初始牌无限控制风险。

## 仍然没有通过验收

1. **老师「指定教材」**的回报与完成长期教案的速度严重不匹配。需要真人研究它在第2、3章的精确牌序和战后模块，而不是简单把所有短教案统一提高减伤。
2. **厨师酸辣苦**虽有高级苦味，但是衔接、回血延迟、伤害减半时机仍不健康；未来应对比苦味首次释放、持续时间与自损豁免的实际收益。
3. **一二捕获路线仍偏强**，但关闭捕获后已不再无代价稳定通关；应继续验证捕获失败、牌库扩张和敌人遗留效果。
4. **职业真人操作未验收**。自动策略可能预知模拟抽牌，不擅长多回合计划，不能作为上线平衡依据。
5. 5/7战后恢复尚未重新定稿：第三章削弱一场精英只带来适度改善，说明老师与苦味瓶颈仍为职业构筑而非单独的敌人HP。

- 手机试玩：`https://zhangcj040221-alt.github.io/game1/adventure/`。

**决议**：在尚未完成五职业真人实玩前，保留13场、9次成长、30 HP、5/7恢复。采用第三章精英单点减生命6的可回退候选值。继续优先修正老师指定教材和厨师苦味的构筑回报；不要为得到整齐胜率而全面削弱敌人或再次大规模重写骑士。
