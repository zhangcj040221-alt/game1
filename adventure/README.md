# 雾林手记 · 三章试玩 R1

从 game1 的 /adventure/ 开始一局。使用 ?lab=teacher 或 ?lab=chef 可从第一章第二战开始，亦可在选角页直接打开第一次战后编排。这两个练习入口使用独立存档。手机点选敌人、点牌出牌，留牌按钮再点一张手牌。每次操作后自动保存在当前浏览器。

## 成长与实验参数

- 正式冒险从30生命开始。布布首战后选职；第2、3、4、6、7、8、10、11、12战后成长。普通胜利恢复5，精英7，前两章首领回满。
- 老师在出第一张有效类别牌前指定短教案目标。短条件、两奖励位、长期组合与一项主导权限可改编。相同奖励最多两级，权限强化一次。整顿的首领削伤和冷却、临时加课的抽牌、指定教材的额外抽牌均由对应强化生效。失败可选补课或失去留牌。长期达到4立即对所有存活敌人造成10点直接生命伤害，幸存者各自跳过一次行动。杂事甲改造后抽二弃一，乙抽一并准备下回合多抽一，二级杂事共享每回合一次免费使用。每战清零。
- 厨师用提炼、转化、做菜替换单个真实牌位。配方和持续时间见 chef.js 和牌面。苦同时抑制治疗、自损与料理输出；试行每战实际治疗合计12。保鲜只对下一张其他味道有效，返牌不可连续保鲜。先用两味再点调和，该回合下一张味道牌免费。基础辣持续当前及下一回合，高级辣持续三回合。
- 骑士每回合免费切姿一次。盾姿独立攻击段与护甲恰等时打断该目标的下一次意图。拔剑倍率只作用于切姿攻击。校盾可以选择减一。成长为等量替换。
- 一二用镜完全格挡、镜接星弹或星印接攻击创造失衡。失衡且敌人生命不高于40%可捕获；血量越低越容易成功，失败扣2生命。普通与首领均可捕获、新牌进手和永久本局牌库。默认用移除处理，可在设置切换孢子死亡遗留做对照。收服魔法跨章节可用。
- 各项新数值为待试玩参数。engine.js 导出 config、遭遇表、意图；职业牌与模块在 teacher.js、chef.js。一切战斗共用目标顺序、死亡、牌堆和回合推进。

## 本轮规则修正（待正式平衡验收）

- 一二的魔法连锁对所有敌人设有恢复窗口：同一目标被一二魔法打断一次后，必须实际完成一次攻击意图才能再次通过魔法连锁或镜反射失衡；蓄力、援护等不解除。此规则只限制一二，老师与骑士的失衡仍照常。试玩设置可关闭“魔法韧性”以复测旧行为。
- 骑士完美格挡维持既定玩法：本次攻击已完全抵挡，目标下一次意图被失衡取消；不赠送额外玩家回合。此处通过专项回归锁定规则，不作为误判漏洞削弱。
- 厨师酸味恢复“先自损、下一次普通攻击追击”的先前方向：基础酸追加原攻击等额伤害，高级酸追加原攻击200%的伤害并抽一张牌；不叠加重复酸倍率。每副牌至少保留2张基础攻击以兑现料理效果。以上百分比为待校准测试参数。

## 复验

在仓库根目录运行 npm ci、npm run build、node --test tools/adventure/rules.mjs 和 npx playwright test。生成构筑数据使用 node tools/adventure/trials.mjs 3。逐战结果含种子、成长次数、进入及恢复前后生命、回合、完美格挡、料理净血量、主导解锁与使用、收服与魔法使用以及击破顺序。阶段探针从满血开始，与连续冒险单独计数。自动策略可以看模拟抽牌，仅用于回归和发现压力点。

角色图直接引用 characters 下的两张 R05。敌人棋子图标及牌面是试玩用占位。发布冒险只需新增 adventure 目录。请勿用冒险构建目录覆盖旧的站点根目录。

### 老师基础牌试玩 R2

老师练习入口加上 &seed=5，选择「老师 · 成长试玩」，起手可直接测试预习。当前回合的已知牌顶显示在战场下方；打出预习后可从揭示的两张里任选一张，另一张留在原处。抽牌堆已经抽空时先回洗。预习与二级杂事共用每回合首次免费整理。板书蓄力从2试调至4；点名单体削弱4，纪律全体削弱2，小测对已削弱目标造成7，其余目标4。提问仍是稳定的6伤。基础杂事仍需靠本场批改改造。

同种子、同目标排序的18局老师回归中，进入第三章从3局增至17局，纪律路线首次通关1局。教材路线完成长期教案仍为0次。上一轮完整报告与压缩数据保留为R1基准，运行 trials.mjs 可重新生成当前结果。

厨师战后每次展示至多三种具体替换。同一张旧牌的相同替换去重。三类机会都合法时，提炼、转化、做菜各出一项；某类缺席则用其他合法替换补位。候选由开局种子与成长节点确定，刷新后不变。可以跳过。

### 工程师成长对照（第二阶段）

工程师战后可选“精修”与“更换图纸”，不再只能反复替换图纸。精修针对某一张已有机关，最多两级，每级让该机关触发伤害+2；更换该牌所在槽位会清空其精修。数值待后续平衡。模拟增加“机关纯替换”对照。

老师仍维持有限的两奖励槽位与一项主导权限，不新增资源。对照模拟将“指定教材”构筑的一处奖励换为“衔接”，实测长期完成后教材权限能否兑现；保留“教材无衔接”旧路径作为对照。

### 小偷与工程师试玩

小偷在首战转职后用5金币采购。每次胜利（最终战除外）可查看下场对手、购买本场三件商品中的若干件。每款限购一件，口袋共两格。普通牌组固定。剩余金币与每件道具的使用次数跨战、跨章保存；袖箭每件两次，连发弩、折叠盾每件三次，急救包每件两次，烟雾弹一次。每名对手有有限且可见的金币。顺手牵羊花一次行动，面对攻击意图取2币、准备意图取3币，以目标余额为限。

工程师的机关图纸循环入牌库。每名敌人可以绑定一件造物，新部署替换旧机关。只有该敌人的意图即将实际执行时才检查机关，符合触发条件即先结算一次，然后拆除；敌人若已死亡则取消动作。也可花1行动手动启动。战后从有限候选中替换一张图纸。机关类型、物价、次数和初始金币均为试玩值。
