# 一二布布美术资产 V01

A 柔光绘本为主版本，B 哑光软陶为辅助版本。本包为首版可复用角色资产，尚待视觉验收。

## 造型
以用户确认的 R05 为唯一几何基准。所有路径、椭圆坐标、部件变换与绘制顺序保持一致；构建脚本逐项断言。原图对比中的生成式角色未作为新母版。一二保留独立鞋子、颈带与领结；布布没有添加鞋子。

## 文件
每版包括两位角色的分层 SVG、1440方形透明 PNG、原坐标部件 SVG 和960方形透明 PNG。layers.json 给出部件绘制顺序；全部画布为统一240×240源坐标，导出部件不裁切，方便按相同原点重新装配。基础造型文件在 baseline/。

## 美术
A：保留深棕轮廓，柔和色阶，细微纸感。B：弱化轮廓，更饱满明暗与微粒表面。均由可编辑渐变与SVG滤镜完成，几何不依赖生成图抽样，材质效果是2.5D烘焙外观。不是三维黏土模型，也不是PSD。光照方向已画入外观，不会因卡牌旋转自动得到新的侧面或真实体积光照。部件独立移动时需检查明暗接缝。

## 接入
沿用现有Three.js分层方式，优先用SVG原始240画布或部件PNG；眼睛与嘴部独立。完整PNG用于静态预览。角色透明材质沿用已修复的alphaTest与depthWrite策略。

asset-review为同场景预览；背景仅用于检查组合效果，未作为正式场景美术交付。未替换当前在线样片。

运行 python build.py 需要 Inkscape。
