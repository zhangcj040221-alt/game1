# 递星星 · 手机卡面验证

两组均能看清星星与两张脸。现有剧情的手部交接未通过。布布递出时和一二接收时，手掌与星星都留有空隙。右侧 20° 的结束画面里，星星叠在一二脸颊前，接收手仍在下方。

[手机卡框](mobile-cards.webp) · [原卡双坐姿](seated.webp) · [布布站姿、一二坐姿](standing.webp) · [逐进度测量](hand-gaps.csv)

| 剧情进度 | 检查部位 | 原卡双坐姿 | 布布站姿、一二坐姿 |
| --- | --- | --- | --- |
| 30% 递出 | 布布递出手 | ≥0.21 | ≥0.36 |
| 68% 交接前 | 布布递出手 / 一二接收手 | ≥0.58 / ≥0.61 | ≥0.48 / ≥0.61 |
| 100% 结束 | 一二接收手 | ≥0.20 | ≥0.20 |

数值以星星模型自身的正面宽度为 1，表示手部网格到星星网格的三维距离下界，按两位小数向下截取。对两者的实际顶点沿多个方向投影，取投影区间间隙的最大值。正值能证明分离。两组各按剧情进度每 1% 取样一次，全部 202 个样本的四只手与星星均分离。

使用原卡 B 的模型工厂、剧情、月光布景与镜头。在宽 390 CSS 像素的 Chromium 视口中，卡面画布为 320 × 420。固定呼吸和眨眼，在同一进度获取左 20°、正面、右 20°。原卡两人均坐。站坐试验只替换递出方为 R23 空手站姿，沿用原动作。18 张样片中四个瞳孔中心均未被星星遮挡，星星中心也均可见。局部图以同一区域裁切。手势的可读性来自画面评估。

当前角色动作绕肩旋转，星星独立沿剧情轨迹平移。下一轮可在两只掌面分别标出持星点，先摆好布布持星和一二接星的首尾姿势，再安排中间交接。现有接收动作只单独驱动一二的一只手，双手捧星仍需另摆。

在仓库根目录运行 `node tools/review/handoff.mjs` 可复现完整画面与数值。依赖项目开发环境和 Playwright Chromium。结果输出在 `test-results/handoff/`。[本次浏览器运行](https://github.com/zhangcj040221-alt/game1/actions/runs/44550303498)
