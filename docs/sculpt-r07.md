# R07 — 耳朵、腮红与颜色（待审核）

用户否决 R06 的耳朵、腮红和布布头部颜色。本次保留头部主体网格，集中修正三处；R06 不视为通过造型验收。

## 问题与修改

- 内耳：此前直接画了一个偏薄的上弦月，形成眉毛状色块。参考图是饱满的深色内耳，被头顶遮住下缘。现在使用完整浅凹内耳区域，由真实头部遮挡形成可见轮廓；减薄外耳深度、降低耳根并调整倾斜。
- 腮红：此前在正面 XY 平面定义圆，再沿 Z 轴投到脸上，实际表面被拉长。改为局部切平面定义圆，沿脸颊法线贴到网格上，避免近侧腮红在斜视角被横向拉宽。仍保留真实透视下的形状变化，不做永远朝向相机的圆片。
- 底色：布布由偏浅棕的 `#D99A68` 调整为试配暖橙棕 `#CE7C4E`；这只是可复现的材质输入色，不声称从照片精确还原了真实物料色。
- 光照：中性审核页的半球补光从 2.2 降至 1.35、填充光 1.1 降至 0.65，取消暖色主灯，曝光从 1.08 调到 1.0，主灯保持形体照明；卡牌剧情页同步降低曝光和填充强度。软陶高光仍存在，布布粗糙度提高至 0.58、镜面强度降至 0.38。
- 腮红色：黄色从浅奶黄调整到暖金黄 `#E9A32E`，粉色改为 `#E99581`，两者使用低反光涂色材质；深色耳朵也独立于领结／鞋材质。

## 颜色证据与限制

用户 IMG_5507(2).jpeg（1200×1200）拿相机布布的人工选区中位数：额头 (795,550)-(895,600) 为 RGB (222,141,85)，中脸 (852,610)-(912,650) 为 (215,132,74)，下脸 (795,684)-(830,704) 为 (225,144,89)，黄脸蛋内部 (860,685)-(879,708) 为 (231,157,49)。这些是该照片显示色，已包含灯光、相机及调色，不直接当作材质底色。原照片未放入公开仓库。

审核页新增四格受控比较，全部使用相同 R07 网格和机位：

1. R06 底色与旧灯光；
2. R06 底色与新中性灯光，隔离灯光影响；
3. R07 材质与新中性灯光；
4. R07 无光照、无色调映射的纯底色，核查颜色输入与 sRGB 输出链路。
