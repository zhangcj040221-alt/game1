# R11 透视复查与手臂修订

用户强调自摄图为随手拍摄、仅作补充。撤销将照片投影比例直接当作物理尺寸的解释：照片有俯视、偏航、透视缩短、遮挡和未知焦距；不同图可能距离与曝光不同。参考中的高光和阴影也不当作曲面边界。R09/R10 中的比例仅为建模提案，不是测量结果。

本轮保留头部与身体总体宽高，手臂由球状组件改为沿前后方向逐渐内收、下弯的圆润前臂，肩根嵌入躯干；略增加腿根融合，保留双腿轮廓。

新增同一模型、同一光照下的透视比较：水平正面、12 度俯视正面、35 度斜前俯视、80 度侧俯视与170度后俯视。72mm 为复查用假设焦距，不宣称还原用户手机参数。其作用是展示机位如何改变投影，避免为贴合一张随拍而扭曲模型。CPU 灯光非实拍环境复原，不能验收颜色。

用户指出仰头感与持方块姿态可能混淆。原代码无固定仰角，但零旋转不等于视觉中性。保持头部网格不变，安装俯仰单独试调为向下 4 度；该数值为待审核姿态参数，不是照片测量。保留相同透视机位下原角度与调整后的对照，避免把摄影角度和雕塑角度混在一起。
