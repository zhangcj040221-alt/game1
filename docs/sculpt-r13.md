R12 腿部不通过。重新交叉查看原始沙发坐姿、吃薯片、喝饮料、骑乘图及用户自摄的正侧背。骑乘/趴伏仅用于理解肢体体积与动作，不当作中性坐姿投影标尺；用户随拍用于补充遮挡、背面和腿的外展。

腿部厚度与姿态改为 body-profile-r13.json 的独立参数。横向半径从 .175 收至 .118，高度半径从 .14 收至 .125；腿绕自身轴线向外展开32度，脚端随同转向，腿根融合从 .095 降至 .045。32度是试稿参数，非照片量测。身体整体总宽不能当作单腿粗细。头部形状、安装角度与材质均不改。

本轮彩色审核仅使用 reference.html 的 R07 WebGL 材质、光照、曝光与色调映射；不再以 Blender CPU 彩色图代替。原始照片的曝光、暖光与高光不作为固有色。历史 CPU 彩色图不能用作颜色验收。

- 原图 IMG_5508：上铺坐姿、凳上吃薯片及侧躺，显示姿态改变不能直接解释为体积改变。手臂和腿必须有独立姿态参数。
- IMG_5511：沙发坐姿、地面喝饮料与吃薯片，交叉观察短腿外展及头下身体的遮挡，不使用帽子、零食等外轮廓推断身体尺寸。
- IMG_5509/5510：骑乘、前伏姿态主要检查手臂连续体积；不将前伏时的投影短身作为坐姿高度。
- IMG_5562 侧向实拍：确认臀部向后、短腿向前的连续关系；前侧腿横向露出也受转向影响。其拍摄距离、俯仰与曝光未知。
- 自摄背面：确认尾巴及连续臀部；不能由后视照片直接量出被遮挡的腿长。
