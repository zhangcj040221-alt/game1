# R14 肩臂与手掌修订

保留 R13 腿部参数、头部及审核材质灯光。R13 侧面肩部出现独立鼓包，前臂又大部分埋在躯干内，形成胸前小按钮。

收小并抬高融入躯干的肩根；前臂从肩侧向前延伸，沿长度向内弯并下落，使露出部分包含掌部而不只是一个小尖端。参考 IMG_5511 的持杯、吃薯片及沙发坐姿，结合 IMG_5562 的肩手侧向关系。左右暂作对称的中性持物准备姿势，不复制单个道具造成的手臂不对称。

待核对：肩侧轮廓是否自然、前臂是否过长、手掌与腿的视觉比例。固定灯光网页截图审核，不以测试通过代替造型验收。
