# R16 手臂路径重建

R15 的固定光照网页截图显示：胸腹已连续，但手臂后端在背面突出两个小块。旧做法把整个椭球拉长，无法合理表达弯臂。

现沿肩根—肘部—掌部的二次曲线路径构建圆润手臂，肩根埋入胸侧，肘部略外转并下落，手掌向前抱。去掉旧椭球向后多出的长度。保留R15胸腹、R13腿部、头部与固定灯光。

R15模型已通过5项浏览器测试，运行43724454277；该检查只证明可运行。R16仍需同光照正侧背截图验证，不能算造型验收。

模型68d3072通过构建、几何检查及5项浏览器测试，运行44014714524。固定光照实图见r16/webgl-review.webp。检查发现：后伸长度已去除，但背侧肩根仍能见到小凸起，不能宣称背面衔接已完全修复；整体身体仍待视觉审核。
