## 定点实验与待验收项

- 另有28次满血定点测试，职业从同一初始牌组真实执行0、3、6、9次换牌或编排，各自挑战第一章第二战或三章首领。数据保留当时的整副牌与教案。另有48次强制集火顺序测试。与连续冒险分开统计。
- 老师衔接路线完成长期13次，权限实际使用12次。指定教材路线未解锁。切换到失败失去留牌后，三条老师路线分别解锁6、25、2次，仍均未通关。建议下一轮先实玩指定教材路线的第二章精英，检查预习与留牌是否足以安排攻击，再决定对失败扣批改的取舍。
- 厨师三种构筑全部保持8张，各有一次通关。优先实玩终章重击前后，比较酸辣自损和咸返牌的行动成本。每战治疗预算12是防拖延的测试值。
- 捕获组终局15–18张，获得魔法实际打出314次，占747次普通出牌的42%。禁捕获对照以8张牌也全部通关。尚不能据此判定扩牌越多越好。捕获孢子默认当作移除，结算死亡增益的同种子对照与规则测试已保留。
- 集火顺序对两职业的方向相反。第一章孢子与追击组合，衔接老师先打孢子剩21生命、先打追击剩17；同场骑士分别剩26与30。仅为种子1满血定点结果。
- 已把部分后排追击的开场改为休整，终章首领重击后加一个休整意图。选角页可关闭这一候选时序。基础生命与5/7恢复保持交接基准。
- 自动测试使用小宽度搜索，可见模拟出的未来抽牌，且不会像真人一样提前规划数个回合。敌人仍使用原型符号，尚缺真机触控长局反馈。

## 复现

运行 node tools/adventure/trials.mjs 3 生成 results.json。加入 --retain-penalty 切换失败惩罚并生成 retain-results.json，加入 --original 可关掉错峰候选。rows 是每场流水，probes 和 focus 为独立定点数据。
